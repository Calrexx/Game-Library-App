# Game Library Demo Project

## 1. Descrion
A Demo Game Library project made with Express.js and vite

## 2.1 Installation for Local Usage on Terminal
1. Clone the repository
2. Run `npm install`
3. Run `npm i express`
4. Start the server with `node --watch app.js`
5. Visit `http://localhost:3000/` either in your browser or CTRL + Left-Click the link in the terminal.

## 2.2 Online Usage
1. You can access the app with this link: https://gamelibraryapp.netlify.app
